# ¿Que es?
  <p>
    Un Currículum Vítae es un documento que contiene información personal, estudios, conocimientos y experiencia laboral de una persona.<br>
    Se utiliza para presentarse al buscar trabajo o para mostrar las propias capacidades.
  </p>

# ¿Como Funciona?
<p>
  Es para que una persona pueda presentar su información de manera ordenada.<br>
  Así, quien lo recibe puede conocer sus estudios, hablidades y experiencia para tener una idea de su formación.
</p>

# Descripción del Repositorio
<p>
  En este repositorio se encuntra mi Currículum Vítae, realizado en Microsoft Word y guardado en formato digital.
</p>

# Contenido
<ul>
   <li>Currículum Vítae: Va a ser el documento con mis datos y la informacion correspondiente.</li>

</ul>

# Herramienta Utilizada

# Objetivo
  <p>
    El objetivo es guardar y presentar mi currículum vítae como parte de un proyecto escolar.
  </p>
